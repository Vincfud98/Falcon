# Logos oficiais das formas de pagamento

Coloque aqui os arquivos oficiais (baixados do brand kit de cada marca). Assim
que o arquivo existir, o admin mostra o logo oficial no lugar da pílula colorida
(a troca é automática — não precisa mexer no código).

Arquivos esperados (SVG de preferência, fundo transparente, ~16px de altura):

- `pix.svg`          — Pix (Banco Central): https://www.bcb.gov.br/estabilidadefinanceira/pix (Marca Pix)
- `mercadopago.svg`  — Mercado Pago: https://www.mercadopago.com.br/developers (Recursos de marca)
- `stripe.svg`       — Stripe: https://stripe.com/br/newsroom/brand-assets

Use sempre os assets oficiais dos brand kits acima (são de uso permitido para
indicar a forma de pagamento). Mantenha os nomes de arquivo exatamente como
listado.
